### 1.5 渐变色方案

```
主渐变 (Primary Gradient) - 用于Hero和核心视觉
从: #0066FF (Quantum Blue)
到:   #7B2FFF (AI Violet)
角度: 135°

辅助渐变 (Secondary Gradient) - 用于装饰和背景
从: #00D4FF (Quantum Cyan)
到:   #00F5D4 (Cyber Teal)
角度: 90°

深度渐变 (Depth Gradient) - 用于深色背景层次
从: #0A1628 (Quantum Deep)
到:   #4A1B89 (Deep Violet)
角度: 180°
```

### 1.6 色彩使用原则

1. **对比度**: 所有文字与背景对比度≥4.5:1（WCAG AA标准）
2. **品牌色占比**: 主品牌色(Quantum Cyan)占比≥60%
3. **背景原则**: 深色背景为主(Deep Space/Night Grey)，浅色元素突出
4. **禁止使用**: 与竞品(Polkadot粉/以太坊蓝紫/Solana绿)过度相似的颜色

## 4. 品牌Logo设计

### 4.1 设计理念

**Qylith = Quantum + Cortex**

视觉符号融合三大核心概念：

1. **量子态 (Quantum State)**: 波函数/概率云的抽象表达
2. **神经网络 (Neural Network)**: 节点与连接的智能网络
3. **安全护盾 (Security Shield)**: 抗量子加密的保护意象

### 4.2 设计原则

```
✓ 极简几何 - 保持视觉清晰度
✓ 动态平衡 - 静态中蕴含动态势能
✓ 可扩展性 - 从favicon到巨幅Banner均适用
✓ 记忆点 - 独特的"Q"变形或独特符号
✗ 避免: 过于复杂的渐变/过多细节/模仿竞品
```

### 4.3 Logo变体

| 版本 | 用途 | 背景要求 |
|-----|------|---------|
| 标准版 | 官网、文档 | 深色/浅色背景均可 |
| 反白版 | 深色背景 | 仅深色背景 |
| 图标版 | 头像、App Icon | 浅色背景 |
| 全名版 | 正式场合 | 根据场景 |

## 6. 视觉元素库

### 6.1 背景纹理

```css
/* 量子网格背景 */
background-image: 
  linear-gradient(rgba(0, 212, 255, 0.03) 1px, transparent 1px),
  linear-gradient(90deg, rgba(0, 212, 255, 0.03) 1px, transparent 1px);

/* 粒子效果背景 */
background: radial-gradient(circle at 20% 80%, rgba(123, 47, 255, 0.15) 0%, transparent 50%),
            radial-gradient(circle at 80% 20%, rgba(0, 212, 255, 0.15) 0%, transparent 50%);
```

### 6.2 装饰元素

- **Quantum Glow**: 发光效果，用于高亮区域
- **Grid Pattern**: 网格背景，增强科技感
- **Floating Particles**: 悬浮粒子，动态装饰
- **Circuit Lines**: 电路纹理，AI/技术暗示

### 6.3 品牌插图风格

```
风格指南:
├── 配色: 量子青蓝 + AI紫为主色调
├── 元素: 几何图形 + 渐变 + 发光效果
├── 角度: 等距视角(Isometric)优先
```

## 7. 竞品视觉差异化

| 竞品 | 主色调 | Qylith差异化策略 |
|-----|-------|----------------|
| **Polkadot** | 粉色系 #E6007A | 使用青蓝色系，区别于粉紫 |
| **Ethereum** | 蓝紫渐变 | 更偏向青色/青色-金色渐变 |
| **Solana** | 绿色系 #00FFA3 | 完全不同的色相 |
| **Cosmos** | 蓝色系 #2E86AB | 加入AI紫作为特色 |
| **Algorand** | 蓝绿渐变 | 强调量子蓝-金渐变 |

**Qylith独特性**: 
- 量子蓝(青) + AI紫的双主色组合
- 金色作为"安全/成就"的点缀色
- 深空黑背景的沉浸式体验
