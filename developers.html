Quick Start

1. Clone the Repository

git clone https://github.com/bahuang081-svg/Qylith.git
cd Qylith

2. Build the Node

# Install Rust (if not installed)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Build release
cargo build --release

3. Run Development Node

# Start with development chain
./target/release/qylith-node --dev

# Or connect to testnet (when available)
./target/release/qylith-node --chain testnet

API Reference

JSON-RPC API

Full JSON-RPC interface for chain interaction. Query blocks, transactions, accounts, and more.

  • • eth_* compatible methods
  • • Custom Qylith methods
  • • WebSocket support

Substrate RPC

Native Substrate RPC for advanced operations including chain state and author API.

  • • state_* queries
  • • author_* for transactions
  • • system_* for node info

AEM API

AI Agent Execution Module API for agent registration, execution, and reputation.

  • • Agent registration
  • • Task submission
  • • Reputation queries
